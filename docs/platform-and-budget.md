# 平台、账号与预算

参考部署为 **Cloudflare Workers Paid + D1**。Workers 提供网关和受保护写入，D1 保存选定公开文本及版本。Core 使用通用源接口，已有线上源可不启用托管。R2 尚未实现，也不属于当前必需服务。

本地 Wrangler/workerd 与模拟 D1 不需要云账号或付费。参考配置不是购买普通 VPS；无需单独租用服务器，再额外购买文字存储套餐。

## 是否必须付费

AIG 契约不要求付费平台。Cloudflare 有 Free 额度，但当前生成配置设置 50ms CPU，上述完整参考路线未完成 Free 套餐适配和验收。维护者选择 Paid 作为小规模运行基线，不应将它表述为 AIG 的固有技术要求。

## 准备清单与入口

| 项目 | 用途与办理 |
| --- | --- |
| Cloudflare 账号 | [注册/登录](https://dash.cloudflare.com/)，使用长期邮箱，保留可恢复的账号访问 |
| 域名与 DNS 权限 | 已有域名可复用子域名；在实际注册商管理，Cloudflare Custom Domain 需要相应 DNS/账号权限 |
| Workers 计划 | 在自己的控制台选择适用方案；本参考路线使用 Paid，不要求购买网站 Pro/Business |
| D1 数据库 | 在自己账号创建专用库并迁移，参考[官方入门](https://developers.cloudflare.com/d1/get-started/) |
| 付款方式 | 仅在官方 Billing 页面提交平台支持的付款方式与真实账单资料；不要放进聊天、配置或仓库 |
| 部署身份 | 使用自己的 Cloudflare 授权；与发布者 token 分离，不共享云管理凭据 |
| 发布者凭据 | 由本工具本地生成并按 scope 分发，不公开 token |
| GitHub | 可复用个人账号，用于源码和版本；不必开启自动云部署 |

注册资料、付款支持和地区条件以平台实际表单及[官方账单说明](https://developers.cloudflare.com/billing/get-started/create-billing-profile/)为准。公开源码不需要公开个人邮箱、住址、付款信息或部署账号标识。

## 价格与假设

以下为 2026-10-21 核对的参考价格，税费、汇率、其他项目共享用量及未来调整另计。

| 项目 | 参考价格 / 额度 |
| --- | --- |
| 本地开发 | 不产生云用量；已激活的套餐仍按账号计费 |
| Workers Paid | 每账号最低 $5/月，含 1,000 万请求与 3,000 万 CPU 毫秒；额外请求 $0.30/百万次、CPU $0.02/百万毫秒 |
| D1 / Paid | 含每月 250 亿行读取、5,000 万行写入和前 5GB 存储；超出读取 $0.001/百万行、写入 $1/百万行、存储 $0.75/GB·月 |
| 域名 | 使用已有域名无新增购置；新域名按后缀、注册商和续费报价另算 |
| R2 / 附件 | 当前不启用；实现和开通前再核算存储与操作费用 |

价格依据：[Workers 官方价格](https://developers.cloudflare.com/workers/platform/pricing/)、[D1 官方价格](https://developers.cloudflare.com/d1/platform/pricing/)。D1 的行数是查询扫描/写入行，不等于请求数；私有版本历史也占存储。

小规模文字试点可先预留 **$5–10/月，加域名续费**，这是预算假设，不是固定报价或封顶。现有 Paid 账号的最低费按账号共享，不能简单给每个项目重复计算一份基础费。实际总成本仍取决于 CPU、请求、数据库与其他启用服务。

## 顺序

先本地复现 → 准备账号/DNS/预算 → 创建专用 D1 → 生成独立配置和新 token → 审阅离线计划/构建 → 运营者执行无入口部署 → 核对绑定 → 开放指定域名 → 合成验收 → 再决定真实使用。

限速和 CPU 上限不等于整月费用封顶。关闭域名不自动停用套餐、删除 D1 或清除数据。域名续费和云服务持续费用由运营者分别管理。
