# 可选托管模块：S3b

只有本地源时，发布工具可将选定公开正文同步为线上副本，由 AIG 提供持续读取。无需让网关回连本机，也不暴露本地数据库。已同步副本的读取不依赖发布机持续在线；新的更新和撤回仍需要成功同步。

对已有线上源的发布者，托管可省略。Core 通过源接口读取，不强制使用集中内容库。本模块不包含内容社区、推荐、计费、注册或多级管理界面。

## 功能与责任

| 部分 | 责任 |
| --- | --- |
| 发布工具 | 选择公开范围，提交精确版本，单独记录结果并同步更新/撤回 |
| `PUT /publish/items/{id}.json` | 校验 Bearer token、发布者范围、Schema、版本和大小 |
| D1 适配器 | 原子保存版本历史与当前状态，识别已接受版本的幂等重试 |
| 公共读取 | manifest、Feed 和详情；撤回仅返回 410 墓碑 |
| 运营方 | 管理 HTTPS、部署、凭据、存储、域名及费用 |

当前实现用 Workers + D1 保存文本。R2 和二进制对象上传尚未实现。读写示例见[发布者接入](publisher-integration.md)。

## 重试和撤回

同一版本规范化 JSON 一致时为 `unchanged`；同版本不同内容、跳号、身份变化返回冲突。旧请求的 `unchanged` 不恢复当前状态，调用方须同时查看 `current_revision` 与 `current_status`。

撤回使用下一连续版本、`status: withdrawn`、原因与空 `representations`。详情返回不含旧正文、标题和扩展的墓碑，Feed 移除该项；公开接口不提供历史版本。响应为 `no-store`。

D1 私有历史保留用于幂等核对。撤回不是物理删除，也不能收回客户端已保存的副本。需要物理擦除时须另行定义存储和重试策略，当前没有相关 API。

## 必要防护

- 公网读写使用 HTTPS，发布凭据仅在授权请求头发送，不跟随重定向转发。
- 每个发布者使用独立的 32 字节随机密钥；服务端限制其 publisher.id 和资源所有者。
- 参考配置包含请求限速 120/60 秒、鉴权失败限速 5/60 秒；这是 Cloudflare 位置级基础限速，不是全局费用上限。
- 请求/资源 256 KiB、响应 2 MiB，超限明确失败；当前 D1 Feed 上限为 100 个已发布资源。
- 不开放匿名 D1 访问、本机路径选择、上游 URL 抓取或公开管理配置。
- 密钥、原始日志、数据库和运行资料不提交仓库；错误响应不打印凭据。

公开读取本身是预期功能。隐藏域名和随机 ID 不替代权限。基础防护降低滥用风险，不代表绝对防护或完整生产压力验收；[测试说明](verification.md)单独列出覆盖范围。
